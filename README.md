# SteganoPro - 专业图片隐写术工具

> 一款专业级的图片文字水印隐藏与还原软件，采用先进的LSB最低有效位算法，将文字信息安全隐藏在图片像素中，人眼完全无法察觉。
> ![加密](/加密.png "加密")

## 🌟 项目特点

- ✅ **完全透明**：仅修改像素最低位，视觉上与原图无任何区别
- 🚀 **大容量**：1080P图片可轻松隐藏近百万字符
- 🔐 **高安全性**：无密钥也无法直接破译，必须使用本工具提取
- 🎨 **专业界面**：现代深色科技风GUI，操作直观简洁
- 💾 **防破坏**：严格使用PNG无损格式保存，水印永不丢失

## 📦 环境要求

- Python 3.8+ 
- Pillow 图像处理库

## 🔧 安装指南

1. 克隆或下载本项目到本地
2. 安装依赖库：
```bash
pip install pillow
```

## 📖 使用教程

### 🔒 隐藏文字水印
1. 点击「选择原始图片」右侧的浏览按钮，选择一张原始图片
2. 在下方大文本框中输入你想要隐藏的文字内容
3. 点击「执行隐藏水印」按钮
4. 在弹出的保存对话框中选择保存位置（默认自动保存在程序目录）
5. 完成！生成的PNG图片中已包含隐藏的文字水印

### 🔓 提取文字水印
1. 点击「选择带水印的图片」右侧的浏览按钮，选择之前生成的带水印图片
2. 点击「提取水印文字」按钮
3. 下方文本框将自动显示出之前隐藏的完整文字内容

## 📐 水印容量计算

隐藏容量与图片像素数量直接相关：

| 图片分辨率 | 总像素数 | 最大可隐藏字符数 |
|-----------|---------|----------------|
| 640×480   | 30万    | 约11万字       |
| 800×600   | 48万    | 约18万字       |
| 1280×720  | 92万    | 约34万字       |
| 1920×1080 | 207万   | 约77万字       |
| 3840×2160 | 830万   | 约310万字      |

**计算公式**：最大字符数 = (像素总数 × 3) ÷ 8 - 9

## 🛠️ 技术原理

本项目采用 **LSB (Least Significant Bit) 最低有效位隐写算法**：

1. 将待隐藏的文字转换为8位二进制序列
2. 遍历图片的每个像素，取出R、G、B三个颜色通道的最低1位
3. 用待隐藏的二进制位逐个替换这些最低有效位
4. 由于最低位的变化对像素值影响微乎其微（仅±1），人眼完全无法察觉
5. 提取时反向操作，从所有像素的最低位中还原出原始的文字二进制序列

## ⚠️ 注意事项

1. **必须使用PNG格式保存**：JPG是有损压缩，会破坏像素细节导致水印丢失
2. 不要对带水印图片进行截图、裁剪、滤镜等修改操作，会破坏隐藏数据
3. 大段文字建议使用大尺寸图片存储
4. 程序默认追加 `###END###` 作为结束标记
